Crater-Agent는 사용 안내, 권한 범위 내 작업 목록과 진단, 노드 및 클러스터 리소스 조회를 제공합니다. 일반 사용자는 현재 활성 계정에 속한 자신의 작업만 조회할 수 있으며 진입점을 바꾸어도 권한이 확대되지 않습니다. 원시 로그 조회와 작업의 직접 생성·중지·삭제는 지원하지 않습니다.

## 도우미 열기

기본적으로 화면 오른쪽 아래에 Crater-Agent 실행 버튼이 표시됩니다. 사이드 패널에서 대화를 만들고, 이름을 변경하고, 삭제하거나 답변 생성을 중지할 수 있습니다.

새 대화의 안내 메시지에는 사용 가능한 기능과 “이런 질문은 어떠세요” 아래에 20가지 주제 중 무작위로 고른 질문 3개가 표시됩니다. 새 대화를 만들 때 다시 뽑으며 입력 중에는 바뀌지 않습니다. 예시 질문을 선택하면 즉시 전송됩니다. 관리자 예시는 사용자 화면의 작업 생성 페이지로 안내하지 않습니다.

개인 설정에서 플로팅 버튼을 숨겨도 다른 페이지에서 제공하는 Agent 진입점은 계속 사용할 수 있습니다.

## 조회와 확인

“최근 실패한 작업 다섯 개만 분석해 줘” 또는 “이 노드의 GPU는 몇 장이야?”라고 질문할 수 있습니다. 자동 조회는 답변 위의 접힌 도구 목록에 표시되고, 페이지 이동이나 폼 변경 확인 카드는 답변 뒤에 표시됩니다. 폼은 자동 제출되지 않습니다. 다음 메시지를 보내기 전에 대기 중인 카드를 확인하거나 취소하세요.

“현재 작업”은 종료되지 않은 작업을 조회합니다. 최근 기록이나 실패·완료 상태를 지정하면 해당 이력을 조회합니다. 정상적인 빈 결과는 해당 범위에 작업이 없음을 의미하며 페이지 분할되거나 생략된 결과는 전체 목록이 아닙니다.

생성 중에는 펼칠 수 없는 상태 표시로 응답 대기, 도구 실행, 답변 생성을 보여 줍니다. 완료되면 숨기고 중지나 실패 시 회전을 멈춥니다. 모델 내부 추론은 표시하지 않으며 결과는 기존 도구 카드를 펼쳐 확인할 수 있습니다. 상태는 임시 화면 표시로 새로고침하거나 대화를 전환하면 복원되지 않습니다.

다른 페이지에서 작업 생성을 요청하면 이동 확인 후에도 사이드 패널이 열린 상태로 유지되고, 새 폼에 로드된 GPU 및 이미지 후보를 바탕으로 입력을 제안합니다. 이미지를 지정하지 않았다면 실제 후보 중 기본 Python 실습에 적합한 이미지를 추천할 수 있습니다. 폼 도우미는 현재 폼에서 허용된 필드만 변경하며, 폼을 다시 열면 새로운 제안이 필요합니다. 가용 리소스는 요청량에 기반한 시점 추정치로, 실제 사용률이나 스케줄링을 보장하지 않습니다. 과거 실패 원인은 해당 작업에 남아 있는 증거를 기준으로 판단합니다.

이동만 요청하거나 입력하지 말라고 명시하면 입력 제안을 자동 생성하지 않습니다. 안전하게 일치하는 후보가 없으면 이유만 설명하고 빈 입력 카드는 표시하지 않습니다.

## 개인 모델 설정

개인 LLM 설정에서 OpenAI 호환 API 기본 URL, 모델 이름 및 API Key를 입력합니다. Crater는 연결을 확인한 후 API Key를 암호화하여 저장하며, 저장된 전체 키는 다시 표시하지 않습니다.

- 완전한 개인 설정은 플랫폼 기본 설정보다 우선합니다.
- 동일한 로그인 사용자는 사용자 화면과 관리자 화면에서 하나의 개인 모델 설정을 공유합니다.
- 사용자 화면과 관리자 화면의 대화 기록은 서로 분리됩니다.
- 개인 설정을 제거하면 관리자가 설정한 플랫폼 기본 모델을 사용합니다.

개인 API는 공개적으로 접근 가능한 HTTPS 주소여야 합니다. 신뢰할 수 없는 모델 서비스를 설정하거나 대화에 비밀번호, Token 또는 기타 민감한 정보를 보내지 마세요.

개인 모델 설정을 저장하거나 제거하면 관리자가 볼 수 있는 작업 로그에 작업자, 시간, 설정 범위와 성공·실패 상태가 기록됩니다. 새 키 제출 여부 등의 메타데이터만 기록하며 키, 엔드포인트 URL, 모델 이름, 원본 요청 및 오류 내용은 기록하지 않습니다. 설정 조회나 연결 테스트만으로는 설정 변경 로그가 생성되지 않습니다.

## 대화와 데이터

대화 제목, 메시지 및 생성 상태는 Crater 데이터베이스에 저장됩니다. 관리자는 플랫폼 관리 업무를 위해 Agent 대화를 검토할 수 있으므로 Crater 관련 내용에만 사용하세요.

AI 생성 내용에는 오류가 있을 수 있습니다. 리소스 변경과 같은 고위험 작업에서는 플랫폼에 표시된 대상, 권한 및 확인 정보를 기준으로 판단하세요.
