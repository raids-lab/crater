Crater-Agent는 Crater에 내장된 플랫폼 도우미입니다. 현재 버전은 플랫폼 사용 안내와 기본 대화를 제공하며 사용자별 대화 기록을 저장합니다. 작업, 이미지, 로그 또는 클러스터의 실시간 정보는 해당 플랫폼 도구가 명시적으로 연결된 경우에만 조회하며 페이지 권한 검사를 우회하지 않습니다.

## 도우미 열기

기본적으로 화면 오른쪽 아래에 Crater-Agent 실행 버튼이 표시됩니다. 사이드 패널에서 대화를 만들고, 이름을 변경하고, 삭제하거나 답변 생성을 중지할 수 있습니다.

개인 설정에서 플로팅 버튼을 숨겨도 다른 페이지에서 제공하는 Agent 진입점은 계속 사용할 수 있습니다.

## 개인 모델 설정

개인 LLM 설정에서 OpenAI 호환 API 기본 URL, 모델 이름 및 API Key를 입력합니다. Crater는 연결을 확인한 후 API Key를 암호화하여 저장하며, 저장된 전체 키는 다시 표시하지 않습니다.

- 완전한 개인 설정은 플랫폼 기본 설정보다 우선합니다.
- 동일한 로그인 사용자는 사용자 화면과 관리자 화면에서 하나의 개인 모델 설정을 공유합니다.
- 사용자 화면과 관리자 화면의 대화 기록은 서로 분리됩니다.
- 개인 설정을 제거하면 관리자가 설정한 플랫폼 기본 모델을 사용합니다.

개인 API는 공개적으로 접근 가능한 HTTPS 주소여야 합니다. 신뢰할 수 없는 모델 서비스를 설정하거나 대화에 비밀번호, Token 또는 기타 민감한 정보를 보내지 마세요.

## 대화와 데이터

대화 제목, 메시지 및 생성 상태는 Crater 데이터베이스에 저장됩니다. 관리자는 플랫폼 관리 업무를 위해 Agent 대화를 검토할 수 있으므로 Crater 관련 내용에만 사용하세요.

AI 생성 내용에는 오류가 있을 수 있습니다. 리소스 변경과 같은 고위험 작업에서는 플랫폼에 표시된 대상, 권한 및 확인 정보를 기준으로 판단하세요.
