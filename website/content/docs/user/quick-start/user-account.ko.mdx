사용자는 자신의 로그인 정보로 Crater에 접속하며 여러 계정에 속할 수 있습니다. 계정은 스케줄링 대기열과 과금 단위를 나타냅니다. 현재 계정은 이후 작업 제출, 계정 저장소 접근, 리소스 할당량 및 과금 조회에 적용됩니다.

## CLI로 계정 확인 및 전환

Crater CLI에 로그인한 상태에서 소속 계정과 현재 계정을 확인한 후 이름으로 계정을 전환합니다.

```bash
crater account ls
crater account current
crater account use research
crater account current
```

`research`를 `account ls`가 반환하는 정확한 `name`으로 바꾸세요. 별명이나 ID는 사용하지 않습니다. 전환에 성공하면 현재 로그인 사용자의 새 인증 정보가 저장되며 이후 명령은 대상 계정을 사용합니다. 다른 저장된 로그인 정보는 유지됩니다. 스크립트와 AI 에이전트는 `--json`을 추가하고 `data.context.queue`에서 현재 계정 이름을 읽을 수 있습니다.

플랫폼이나 로그인 사용자를 바꾸려면 `crater auth switch`를, 같은 사용자의 계정을 바꾸려면 `crater account use <name>`을 사용하세요.
