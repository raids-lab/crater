A user signs in with their own identity and can belong to multiple accounts. An account determines the scheduling queue and billing context. The current account determines the context for subsequent job submissions, account storage access, resource quotas, and billing queries.

## Inspect and switch accounts with the CLI

With the Crater CLI already signed in, list your accounts, inspect the current account, and switch by account name:

```bash
crater account ls
crater account current
crater account use research
crater account current
```

Replace `research` with an exact `name` returned by `account ls`, rather than a nickname or ID. A successful switch saves new credentials for the current login identity, and subsequent commands use the target account. Other saved identities stay unchanged. Scripts and AI agents can add `--json` and read the current account name from `data.context.queue`.

Use `crater auth switch` to change platforms or login identities. Use `crater account use <name>` to switch accounts for the same user.
