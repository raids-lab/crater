---

ユーザーは自分のログイン情報で Crater にアクセスし、複数のアカウントに所属できます。アカウントはプロジェクトのスケジューリングキューと課金の単位です。現在のアカウントは、以降のジョブ送信、アカウントストレージへのアクセス、リソースクォータ、課金情報の照会に適用されます。

## CLI でアカウントを確認・切り替える

Crater CLI にログインした状態で、所属するアカウントと現在のプロジェクトを確認し、名前を指定して切り替えます。

```bash
crater account ls
crater account current
crater account use research
crater account current
```

`research` を `account ls` が返す正確な `name` に置き換えてください。ニックネームや ID は使用しません。切り替えに成功すると、現在のログインユーザーの認証情報が保存され、以降のコマンドに適用されます。他の保存済みログイン情報は維持されます。スクリプトや AI エージェントは `--json` を追加し、`data.context.queue` から現在のアカウント名を取得できます。

プラットフォームやログインユーザーを切り替える場合は `crater auth switch`、同じユーザーのプロジェクトアカウントを切り替える場合は `crater account use <name>` を使用します。
