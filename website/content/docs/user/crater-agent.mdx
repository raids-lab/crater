---
title: Crater-Agent
description: 配置并使用 Crater 平台智能助手
---

Crater-Agent 是 Crater 内置的平台智能助手，支持平台使用咨询、授权作业列表与诊断查询，以及节点和集群资源查询。普通用户只能查询自己在当前活动账户下的作业；切换入口不会扩大权限。当前不支持读取原始日志，也不会直接创建、停止或删除作业。

## 打开助手

默认情况下，页面右下角会显示 Crater-Agent 悬浮入口。打开侧窗后可以创建、重命名或删除对话，也可以停止正在生成的回答。

新对话的欢迎消息会列出可用功能，并在“你或许想问”下从 20 个不同主题的示例问题中随机展示 3 个；新建对话时重新抽选，输入过程中不会变动。点击示例直接发送问题；管理端示例不会引导你进入用户端创建页面。

在个人设置中关闭“显示 Crater-Agent 悬浮入口”后，悬浮按钮会隐藏，但其他页面提供的 Agent 功能入口仍可打开侧窗。

## 查询与确认操作

可以询问“只分析最近五个失败作业”或“这个节点有多少张 GPU”。自动查询显示在回答顶部的折叠工具列表中；正文后的卡片用于确认页面跳转或表单填写，不会自动提交表单。未处理的确认卡片需先确认或取消，再继续发送消息。

“现在有什么任务”默认查询未结束作业；“最近记录”或明确指定失败、完成等状态时查询相应历史。成功的空查询表示该范围内没有作业；分页或省略结果不代表全部记录。

生成期间仅显示不可展开的状态提示，如等待响应、工具执行和正文生成；完成后隐藏，停止或失败时停止转动。不展示模型内部推理；具体结果仍可展开工具卡片查看。状态属于当前页面的临时显示，刷新或切换对话后不会恢复。

从其他页面提出创建并协助配置作业的要求时，确认跳转后侧窗会保持打开，并根据新表单和已加载的 GPU、镜像选项继续生成填写建议；只要求跳转或明确暂不填写时，不自动生成建议。没有指定镜像时，助手可从实际候选中建议适合基础 Python 调试的镜像。没有可靠匹配时仅说明原因，不显示空的填写卡片。表单辅助只修改当前页面允许的字段；离开后重新打开表单，需要重新生成建议。节点可用资源是根据资源申请量计算的瞬时估算，不代表实时利用率或调度保证；历史失败原因只能依据对应作业保留下来的证据判断。

## 配置个人模型

在个人设置的“个人 LLM 配置”中填写 OpenAI 兼容接口的 API 基础地址、模型名称和 API Key。平台会先验证连接，再加密保存 API Key；保存后不会再次返回完整密钥。

- 完整的个人配置优先于平台默认配置。
- 同一登录用户在用户端和管理端共用个人模型配置。
- 用户端和管理端的对话历史相互隔离。
- 移除个人配置后，自动恢复使用管理员配置的平台默认模型。

个人接口必须使用公开可访问的 HTTPS 地址。请勿将不受信任的模型服务配置为个人接口，也不要在对话中发送密码、Token 或其他敏感信息。

保存或移除个人模型配置会记录到管理员可查阅的操作日志中，包括操作人、时间、配置范围和成功或失败状态。日志只记录是否提交新密钥等元数据，不记录密钥、接口地址、模型名称或原始请求与错误内容；单独查看配置或测试连接不产生配置变更日志。

## 会话与数据

会话标题、消息和生成状态保存在 Crater 数据库中。刷新页面或更换设备后，可以继续查看已有会话。管理员可依据平台管理职责查看 Agent 对话记录，因此请仅使用 Crater-Agent 处理与平台相关的内容。

AI 生成内容可能存在偏差。执行资源修改或其他高风险操作时，应以平台页面展示的对象、权限和确认信息为准。
