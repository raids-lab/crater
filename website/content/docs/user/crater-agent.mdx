---
title: Crater-Agent
description: 配置并使用 Crater 平台智能助手
---

Crater-Agent 是 Crater 内置的平台智能助手。当前版本提供平台使用咨询和基础对话，并保存每个用户的会话历史。涉及作业、镜像、日志或集群实时状态的问题，只有在对应平台工具明确接入后才会执行查询；助手不会代替页面权限检查。

## 打开助手

默认情况下，页面右下角会显示 Crater-Agent 悬浮入口。打开侧窗后可以创建、重命名或删除对话，也可以停止正在生成的回答。

在个人设置中关闭“显示 Crater-Agent 悬浮入口”后，悬浮按钮会隐藏，但其他页面提供的 Agent 功能入口仍可打开侧窗。

## 配置个人模型

在个人设置的“个人 LLM 配置”中填写 OpenAI 兼容接口的 API 基础地址、模型名称和 API Key。平台会先验证连接，再加密保存 API Key；保存后不会再次返回完整密钥。

- 完整的个人配置优先于平台默认配置。
- 同一登录用户在用户端和管理端共用个人模型配置。
- 用户端和管理端的对话历史相互隔离。
- 移除个人配置后，自动恢复使用管理员配置的平台默认模型。

个人接口必须使用公开可访问的 HTTPS 地址。请勿将不受信任的模型服务配置为个人接口，也不要在对话中发送密码、Token 或其他敏感信息。

## 会话与数据

会话标题、消息和生成状态保存在 Crater 数据库中。刷新页面或更换设备后，可以继续查看已有会话。管理员可依据平台管理职责查看 Agent 对话记录，因此请仅使用 Crater-Agent 处理与平台相关的内容。

AI 生成内容可能存在偏差。执行资源修改或其他高风险操作时，应以平台页面展示的对象、权限和确认信息为准。
