---
title: Crater-Agent
description: Crater プラットフォームアシスタントの設定と利用
---

Crater-Agent は Crater に組み込まれたプラットフォームアシスタントです。現在はプラットフォームの利用案内と基本的な対話を提供し、ユーザーごとの会話履歴を保存します。ジョブ、イメージ、ログ、クラスタのリアルタイム情報は、対応するプラットフォームツールが明示的に接続された場合のみ照会され、ページの権限確認を回避することはありません。

## アシスタントを開く

既定では画面右下に Crater-Agent の起動ボタンが表示されます。サイドパネルでは会話の作成、名前変更、削除、生成停止ができます。

個人設定でフローティングボタンを非表示にしても、他のページに用意された Agent の入口は利用できます。

## 個人モデルを設定する

「個人 LLM 設定」で OpenAI 互換 API のベース URL、モデル名、API Key を入力します。接続確認後に API Key は暗号化して保存され、完全なキーが再表示されることはありません。

- 完全な個人設定はプラットフォームの既定設定より優先されます。
- 同じログインユーザーはユーザー画面と管理画面で同じ個人モデル設定を共有します。
- ユーザー画面と管理画面の会話履歴は分離されます。
- 個人設定を削除すると、管理者が設定したプラットフォーム既定モデルに戻ります。

個人 API は、公開アクセス可能な HTTPS エンドポイントである必要があります。信頼できないモデルサービスを設定したり、パスワードや Token などの機密情報を会話に送信したりしないでください。

## 会話とデータ

会話タイトル、メッセージ、生成状態は Crater データベースに保存されます。管理業務の一環として管理者が Agent の会話を確認できるため、Crater に関係する内容だけを扱ってください。

AI の生成内容には誤りが含まれる場合があります。リソース変更などの高リスク操作では、プラットフォームに表示される対象、権限、確認内容を優先してください。
