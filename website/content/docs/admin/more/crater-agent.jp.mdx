---
title: Crater-Agent 管理
description: プラットフォームモデルの設定と Agent 会話の確認
---

Crater-Agent は、個人モデルを設定していないユーザーにプラットフォーム既定の LLM 設定を提供します。管理者は「プラットフォーム設定 / LLM 設定」で OpenAI 互換 API のベース URL、モデル名、API Key を管理します。

## 設定の優先順位

プラットフォーム既定設定はすべてのユーザーが利用できます。ユーザーが完全な個人設定を保存すると、ユーザー画面と管理画面の AI 機能で個人設定が優先されます。個人設定を削除すると既定設定に戻ります。

API Key は暗号化して保存され、完全な値は再表示されません。モデル設定の更新は以後のリクエストに反映され、既存の会話メッセージは変更されません。

## 会話の確認

「インテリジェント運用 / Agent 会話記録」では、プラットフォーム全体の Agent 会話を確認できます。ユーザー名、表示名、ユーザー ID、タイトル、ID 種別で絞り込み、メッセージを表示できます。

同じログインユーザーでも、ユーザー画面と管理画面の会話は分離され、ID 種別が表示されます。確認機能は読み取り専用であり、管理者が所有者として会話を続行または変更することはできません。

Agent 会話にはユーザー入力とモデル出力が含まれる場合があります。プラットフォーム管理、障害調査、コンプライアンスに必要な場合に限り、組織のデータアクセス規則に従って利用してください。

## デプロイ要件

Helm Chart は Crater-Agent をクラスタ内部サービスとしてデプロイします。認証済みの Crater バックエンドだけがアクセスでき、バックエンドと Agent は同じ内部 Token を使用する必要があります。この Token をブラウザや一般ユーザーに公開しないでください。
