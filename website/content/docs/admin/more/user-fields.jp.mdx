ユーザー管理の表示は `backendConfig.userFields` で設定します。LDAP やローカル認証とは独立しています。LDAP マッピングは取得元を指定し、表示設定は保存済みの情報の見せ方を指定します。

## 設定例

次の設定を Helm values に追加し、通常の手順で適用してバックエンドを再起動してください。フロントエンドの再読み込み後、身分と日時の列が表示され、電話番号の入力欄は非表示になります。

```yaml
backendConfig:
  userFields:
    identity:
      showInTable: true
      showInForm: true
      labels:
        zh: 身份
        en: Position
        ja: 身分・職位
        ko: 신분/직책
    teacher:
      labels:
        zh: 直属领导
        en: Supervisor
    phone:
      showInForm: false
    createdAt:
      showInTable: true
    lastLoginAt:
      showInTable: true
```

LDAP の身分・職位の取得元は別に設定します。ディレクトリの `title` に保存されている場合は、`backendConfig.auth.ldap.attributeMapping.identity: title` を指定します。このプロフィール項目は権限ロールに影響しません。

## 既定の動作

`userFields` を省略するか `{}` にすると、既存の画面を維持します。`showInTable` と `showInForm` はそれぞれ次の既定値を上書きし、省略した設定は既定値のままです。

| 項目 | 一覧 | 編集フォーム |
| --- | --- | --- |
| `nickname` | 非表示 | 表示 |
| `email` | 非表示 | 表示 |
| `identity` | 非表示 | 非表示 |
| `group` | 表示 | 表示 |
| `teacher` | 表示 | 表示 |
| `phone` | 非表示 | 表示 |
| `expiredAt` | 非表示 | 非表示 |
| `createdAt` | 非表示 | 非表示 |
| `lastLoginAt` | 非表示 | 非表示 |

- `showInTable: false` は列と列選択メニューの項目を削除します。
- フォームに表示されない属性は、他の項目を編集しても保持されます。
- LDAP マッピングの未設定、ユーザーの空値、認証方式の変更によって列が自動的に非表示になることはありません。
- ユーザー名、権限、状態、利用制限、操作などのシステム列は対象外です。
- `expiredAt`、`createdAt`、`lastLoginAt` は読み取り専用で、`showInForm: true` を設定できません。
- 非表示は画面表示のみの設定で、権限や API の返却データは変わりません。

## 多言語の項目名

`labels` のキーには `zh`、`en`、`ja`、`ko`、または `en-US` などの地域付き言語を使用します。現在の地域付き言語、基本言語、組み込み翻訳の順に解決します。空白の名称もフォールバックします。列見出し、列選択、編集フォームで共通の規則を使います。

## 日時とアップグレード

- 登録日時は Crater のログイン用プロフィールの作成日時です。LDAP 初回ログイン時の自動登録日時であり、ディレクトリの作成日時ではありません。
- 最終ログイン日時は LDAP・ローカルログイン、または登録後の自動ログインが成功した場合のみ更新します。失敗、トークン更新、セッション復元、プロジェクト切り替えでは更新しません。
- 既存ユーザーの履歴は次の成功したログインまで不明となり、`—` を表示します。空または無効な日付も `—` です。
- アップグレードで NULL を許可する `users.last_login_at` を追加し、過去の値を推測して埋めることはありません。Helm のバックエンド Pod の `migration` init コンテナが起動前に移行を実行します。Helm 以外の構成は既存の移行手順を先に実行してください。

## 読み込み失敗

項目設定を読み込めない場合は再試行ボタンを表示します。ユーザー一覧やポイントの取得失敗もエラーを表示し、表の更新ボタンで関連データを再取得します。
