title: Crater-Agent 관리
description: 플랫폼 모델 설정 및 Agent 대화 검토
---

Crater-Agent는 개인 모델을 설정하지 않은 사용자에게 플랫폼 기본 LLM 설정을 제공합니다. 관리자는 **플랫폼 설정 / LLM 설정**에서 OpenAI 호환 API 기본 URL, 모델 이름 및 API Key를 관리합니다.

## 설정 우선순위

플랫폼 기본 설정은 모든 사용자가 사용할 수 있습니다. 사용자가 완전한 개인 설정을 저장하면 사용자 화면과 관리자 화면의 AI 기능에서 개인 설정을 우선 사용합니다. 개인 설정을 제거하면 플랫폼 기본 설정으로 돌아갑니다.

API Key는 암호화하여 저장하며 전체 값을 다시 표시하지 않습니다. 모델 설정 변경은 이후 요청에 적용되며 기존 대화 메시지를 변경하지 않습니다.

## Agent 런타임 구성

**지능형 운영 / Agent 구성**에서는 중국어와 영어 탭을 전환하여 기본 프롬프트, 플랫폼 지식, 양식 지원 및 작업 진단 규칙, 제목 프롬프트, 프롬프트 인젝션 탐지 규칙을 관리할 수 있습니다. 저장 후 새 Agent 요청은 데이터베이스의 최신 구성을 사용하며 기존 대화 메시지는 변경되지 않습니다.

신원 분리, 백엔드 권한 검사, 도구 목록, 경로 허용 목록 및 사용자 확인 요구사항은 코드에서 강제되며 이 페이지에서 완화할 수 없습니다. 변경 사항은 플랫폼 전체의 이후 Agent 답변에 영향을 주므로 저장 전에 두 언어의 전체 내용을 검토하세요.

## 대화 검토

**지능형 운영 / Agent 대화 기록**에서는 플랫폼의 Agent 대화를 확인할 수 있습니다. 사용자 이름, 닉네임, 사용자 ID, 제목 및 신원 범위로 필터링한 후 메시지를 볼 수 있습니다.

동일한 로그인 사용자라도 사용자 화면과 관리자 화면의 대화는 분리되며 신원 범위가 표시됩니다. 검토 기능은 읽기 전용이므로 관리자가 소유자 자격으로 대화를 계속하거나 변경할 수 없습니다.

Agent 대화에는 사용자 입력과 모델 출력이 포함될 수 있습니다. 플랫폼 관리, 문제 해결 또는 규정 준수에 필요한 경우에만 조직의 데이터 접근 정책에 따라 확인하세요.

## 배포 요구 사항

Helm Chart는 Crater-Agent를 클러스터 내부 서비스로 배포합니다. 백엔드와 Agent는 서비스 인증 Token을 공유하지만 사용자 컨텍스트 서명 키는 백엔드만 보유하고 API Key 암호화 키도 백엔드에서 사용합니다. 각 값은 독립적인 고엔트로피 Kubernetes Secret으로 제공하고 브라우저나 플랫폼 사용자에게 공개하지 마세요.
