---
title: Crater-Agent 管理
description: 配置平台默认模型并审查 Agent 会话
---

Crater-Agent 使用平台默认 LLM 配置为未设置个人模型的用户提供服务。管理员可以在“平台设置 / LLM 配置”中维护 OpenAI 兼容接口的 API 基础地址、模型名称和 API Key。

## 配置优先级

平台默认配置对所有用户可用。用户在个人设置中保存完整配置后，其用户端和管理端 AI 功能都优先使用个人配置；移除个人配置后自动回退到平台默认配置。

API Key 会加密保存，管理页面不会重新显示完整密钥。更新模型配置会影响后续请求，不会改写已有会话消息。

## 配置变更审计

“操作日志”会记录个人模型配置的保存、移除以及平台默认模型配置的保存、重置，可按“保存模型配置”或“移除模型配置”筛选。日志包含操作人、时间、配置范围、结果和个人配置所属用户 ID；保存操作还会记录是否提交新密钥，沿用已保存密钥时为否。失败的配置变更也会记录，但单纯查看配置、测试连接不会记录为变更。

审计仅保留白名单元数据，不记录 API Key 的原文、前后缀或密文，也不记录接口地址、模型名称、请求体和原始错误内容。审计写入失败会记录后台错误，不会撤销已经保存成功的模型配置；此日志不是配置备份。

## 会话审查

“智能运维 / Agent 对话记录”首先按“用户 + 身份”分组，只显示已有会话记录的用户。可按用户名、昵称、用户 ID 和身份筛选，点击用户后查看其会话列表，再打开具体对话查看正文和只读工具记录。

同一登录用户的用户端与管理端会话相互隔离，并在审查列表中标明身份范围。审查功能只提供读取能力，不允许管理员以会话所有者身份继续对话或修改历史。

Agent 会话可能包含用户输入和模型输出。管理员应仅在平台管理、问题排查或合规需要时访问，并遵循组织的数据访问制度。

## 部署要求

管理端助手可按用户名查询全平台作业并读取诊断信息，也能查询节点容量。页面跳转仅限管理端，打开具体作业时直接进入该作业的管理详情页，不会跳到用户端。页面上下文只说明当前对象，不授予额外权限。

Crater-Agent 由 Helm Chart 作为集群内部服务部署，只接受 Crater 后端发起的认证请求。后端与 Agent 必须使用同一个内部 Token；该 Token 不应提供给浏览器或普通用户。
