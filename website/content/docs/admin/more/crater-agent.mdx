---
title: Crater-Agent 管理
description: 配置平台默认模型并审查 Agent 会话
---

Crater-Agent 使用平台默认 LLM 配置为未设置个人模型的用户提供服务。管理员可以在“平台设置 / LLM 配置”中维护 OpenAI 兼容接口的 API 基础地址、模型名称和 API Key。

## 配置优先级

平台默认配置对所有用户可用。用户在个人设置中保存完整配置后，其用户端和管理端 AI 功能都优先使用个人配置；移除个人配置后自动回退到平台默认配置。

API Key 会加密保存，管理页面不会重新显示完整密钥。更新模型配置会影响后续请求，不会改写已有会话消息。

## Agent 运行配置

“智能运维 / Agent 配置”提供中文和英文两个配置页签，用于维护基础提示词、平台知识、表单辅助与作业诊断规则、标题提示词和提示注入识别规则。保存后，新一轮 Agent 请求会读取数据库中的最新配置；已有会话消息不会被改写。

身份隔离、后端权限校验、工具清单、路由白名单和用户确认机制固定在代码中，不能通过该页面放宽。运行配置会影响平台上的后续 Agent 回答，保存前应同时检查两种语言的全部内容。

## 会话审查

“智能运维 / Agent 对话记录”展示平台中的 Agent 会话。管理员可以按用户名、昵称、用户 ID、标题和身份范围筛选，并查看对话消息。

同一登录用户的用户端与管理端会话相互隔离，并在审查列表中标明身份范围。审查功能只提供读取能力，不允许管理员以会话所有者身份继续对话或修改历史。

Agent 会话可能包含用户输入和模型输出。管理员应仅在平台管理、问题排查或合规需要时访问，并遵循组织的数据访问制度。

## 部署要求

Crater-Agent 由 Helm Chart 作为集群内部服务部署，只接受 Crater 后端发起的认证请求。后端与 Agent 共享服务认证 Token；用户上下文签名密钥仅由后端持有，API Key 加密密钥也由后端使用。这些密钥必须通过 Kubernetes Secret 提供高强度独立值，不应暴露给浏览器或平台用户。
