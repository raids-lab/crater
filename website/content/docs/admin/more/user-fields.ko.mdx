사용자 관리 화면은 `backendConfig.userFields`로 설정하며 LDAP 및 로컬 인증 방식과 독립적입니다. LDAP 매핑은 디렉터리 속성의 출처를 지정하고, 표시 설정은 저장된 프로필 정보를 보여 주는 방법을 지정합니다.

## 설정 예시

다음 내용을 Helm values에 병합하고 기존 배포 절차에 따라 적용한 뒤 백엔드를 다시 시작하세요. 프론트엔드를 새로고침하면 신분과 시간 열이 표시되고 전화번호 입력란은 숨겨집니다.

```yaml
backendConfig:
  userFields:
    identity:
      showInTable: true
      showInForm: true
      labels:
        zh: 身份
        en: Position
        ja: 身分・職位
        ko: 신분/직책
    teacher:
      labels:
        zh: 直属领导
        en: Supervisor
    phone:
      showInForm: false
    createdAt:
      showInTable: true
    lastLoginAt:
      showInTable: true
```

LDAP 신분/직책의 출처는 별도로 설정합니다. 디렉터리의 `title`을 사용하는 경우 `backendConfig.auth.ldap.attributeMapping.identity: title`을 지정합니다. 이 프로필 필드는 권한 역할에 영향을 주지 않습니다.

## 기본 동작

`userFields`를 생략하거나 `{}`로 설정하면 기존 화면을 유지합니다. 각 필드의 `showInTable`과 `showInForm`은 아래 기본값을 개별적으로 재정의하며 생략한 옵션은 기본값을 유지합니다.

| 필드 | 표 | 편집 양식 |
| --- | --- | --- |
| `nickname` | 숨김 | 표시 |
| `email` | 숨김 | 표시 |
| `identity` | 숨김 | 숨김 |
| `group` | 표시 | 표시 |
| `teacher` | 표시 | 표시 |
| `phone` | 숨김 | 표시 |
| `expiredAt` | 숨김 | 숨김 |
| `createdAt` | 숨김 | 숨김 |
| `lastLoginAt` | 숨김 | 숨김 |

- `showInTable: false`는 열과 열 선택 메뉴의 해당 항목을 제거합니다.
- 양식에서 숨겨진 속성은 다른 프로필 정보를 수정할 때 유지됩니다.
- LDAP 매핑 누락, 빈 사용자 값, 인증 방식 변경만으로 열을 자동으로 숨기지 않습니다.
- 사용자 이름, 권한, 상태, 이용 제한, 작업 등의 시스템 열은 이 설정의 대상이 아닙니다.
- `expiredAt`, `createdAt`, `lastLoginAt`은 읽기 전용이며 `showInForm: true`로 설정할 수 없습니다.
- 숨김은 화면 표시에만 적용되며 권한이나 API 응답 데이터는 변경하지 않습니다.

## 다국어 이름

`labels` 키로 `zh`, `en`, `ja`, `ko` 또는 `en-US` 같은 지역별 언어를 사용할 수 있습니다. 현재 지역별 언어, 기본 언어, 내장 번역 순서로 이름을 선택합니다. 공백 이름도 대체 규칙을 사용하며 표 제목, 열 선택 메뉴, 편집 양식이 같은 규칙을 따릅니다.

## 시간과 업그레이드

- 가입 시간은 Crater 로그인 프로필이 생성된 시각입니다. LDAP 사용자는 최초 자동 등록 시각이며 디렉터리 사용자 생성 시각이 아닙니다.
- 마지막 로그인 시간은 LDAP 로그인, 로컬 로그인 또는 가입 후 자동 세션 생성이 성공한 경우에만 갱신됩니다. 실패, 토큰 갱신, 세션 복원, 프로젝트 전환에서는 갱신되지 않습니다.
- 기존 사용자의 과거 로그인 시간은 다음 로그인 성공 전까지 알 수 없으므로 `—`로 표시됩니다. 비어 있거나 잘못된 날짜도 `—`로 표시됩니다.
- 업그레이드 시 nullable 열인 `users.last_login_at`을 추가하며 과거 값을 추정해서 채우지 않습니다. Helm 백엔드 Pod의 `migration` init 컨테이너가 시작 전에 마이그레이션을 실행합니다. Helm 이외의 배포는 기존 마이그레이션 절차를 먼저 실행해야 합니다.

## 불러오기 실패

필드 설정을 불러오지 못하면 재시도 버튼을 표시합니다. 사용자 목록이나 포인트 조회 실패 시에도 오류를 표시하며 표의 새로고침 버튼으로 관련 데이터를 다시 불러옵니다.
